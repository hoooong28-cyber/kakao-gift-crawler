# 카카오 선물하기 랭킹 크롤러 및 B2B 인사이트 파이프라인 🎁

카카오 선물하기 랭킹 (카테고리 5: 리빙/주방/디지털/팬시 등) 데이터를 자동으로 크롤링하고, 파생 스키마 생성, 한국어 형태소/키워드 추출, 가격대 x 카테고리 매트릭스(White Space Analysis), USP 속성 비율, 라이징 아이템 감지 및 대시보드 연동용 JSON 카드를 자동 추출하는 B2B 마케팅/기획 파이프라인입니다.

---

## 📁 프로젝트 구조

```
kakao_gift_crawler/
├── main.py              # 데이터 수집, 파생 스키마 가공 및 B2B 인사이트 전체 메인 실행 파일
├── crawler.py           # Playwright 기반 Top 50~100 크롤링 동적 스크립트
├── analytics.py         # 파생 컬럼 생성, 키워드 이원화 추출, USP/White Space 분석 모듈
├── auditor.py           # 데이터 품질 검수 및 100점 점수화 감사 스크립트
├── server.py            # 대시보드 API 서버 및 로컬 웹 서버
├── requirements.txt      # 파이썬 의존성 패키지 목록
├── run_crawler.bat      # 배치 실행 파일 (main.py 자동 실행 + 로깅)
├── setup_scheduler.bat  # Windows 작업 스케줄러 자동 등록 파일 (매일 10시)
├── data/                # 일별 ranking_YYYYMMDD.csv 및 ranking_master_history.csv
├── reports/             # 품질 감사 리포트 (audit_report_YYYYMMDD.md)
└── web/                 # 웹 대시보드 및 JSON 출력 (insight_cards.json, data.json)
```

## 🚀 파생 수집 스키마 (Pandas DataFrame / DB)

1. `price_tier`: 가격대 구간 분류 (`'1만원 미만'`, `'1만원대'`, `'2만원대'`, `'3만원대'`, `'4만원대'`, `'5만원 이상'`)
2. `has_packaging`: 선물포장/쇼핑백/전용패키지/파우치/리본 포함 여부 (Boolean)
3. `has_engraving`: 각인/메시지/메시지카드/문구 포함 여부 (Boolean)
4. `is_exclusive`: 단독/1+1/세트/기획/증정/본품 구성 여부 (Boolean)
5. `is_new_entry`: 직전 수집 대비 신규 랭킹 진입 여부 (Boolean)
6. `rank_delta`: 직전 수집 대비 순위 변동폭 `(이전 순위 - 현재 순위)` (Integer)

## 📊 카테고리별 추천 키워드 모듈 (Recommended Keywords)

- **분석 범위 파라미터화**: Top 50 ~ Top 100 가변 지정 (`--top_n 100`)
- **랭킹 구간별 키워드 이원화 추출**:
  - `Top 1~30 (안정권 키워드)`: 상위권 브랜드 필수/기본 키워드
  - `Top 31~100 (트렌드/라이징 키워드)`: 중위권/급상승 상품 신규 트렌드 키워드
- **키워드 성격별 Top 5 분류**:
  - `[속성/혜택]`: 각인, 선물포장, 단독, 쇼핑백, 세트 등
  - `[타깃/시즌]`: 생일, 응원, 집들이, 답례품, 기념일 등
  - `[콘셉트/제형]`: 데스크테리어, 퍼퓸, 비건, 키링, 파우치 등

## 💻 실행 방법

### 1. 고도화 파이프라인 실행
```cmd
py -3 main.py --top_n 100
```

### 2. 가공 데이터만 재분석 (수집 패스)
```cmd
py -3 main.py --skip_scrape

### 3. 데이터 품질 자체 검수 실행

```

### 4. 대시보드 서버 가동
```cmd

```


## 신규 진입·순위 비교 기준
- 동일 카테고리의 상품 ID로 직전 수집일과 비교합니다. 상품명 변경은 신규 진입으로 보지 않습니다.
- ID가 없으면 카카오 상품 URL에서 ID를 추출합니다. 식별 불가·중복된 이전 기록은 비교 불가로 처리합니다.
- NEW는 직전 수집 범위 안에서 이전에 관측되지 않은 상품입니다. 신상품 출시를 의미하지 않습니다.
- 수집 범위가 Top 50에서 Top 100으로 늘어난 경우, 이전에 없던 51~100위는 비교 불가입니다.
- 급상승 카드는 10계단 이상 상승 또는 확인된 NEW만 포함합니다. 주말·미수집일을 건너뛰면 24시간 비교가 아닙니다.
- 과거 데이터 재계산: `python rebuild_rankings.py` (먼저 data/와 docs/ 백업 권장).
- 회귀 테스트: `python -m unittest discover -s tests -p "test_rank_comparison.py"`

## 대시보드 집계 기준

- `docs/metrics.js`가 요약, B2B IP 비중, IP 전략 표의 공통 집계 기준입니다.
- 개별 IP명이 있는 기록만 IP 비중과 인기 IP 순위에 포함합니다. `기타 캐릭터/팬시` 및 `캐릭터/팬시-*` 그룹은 미분류로 따로 표시합니다. 자동 분류의 정확성을 보증하는 지표는 아닙니다.
- 분모는 선택한 카테고리의 랭킹 기록 수입니다. 동일 상품의 여러 카테고리 노출을 각각 셉니다. 고유 상품 수는 상품 ID (없으면 카카오 상품 URL의 ID)로 중복 제거하고, 식별 불가 기록은 별도로 표시합니다.
- 콜라보는 각 IP별 노출에 포함하되 IP 상품 비중의 분자에서는 한 기록으로 셉니다.
- IP 평균 표시가격은 개별 IP명이 있고 양수 가격을 확인할 수 있는 기록만 사용합니다. 매출이나 소비자 수용 적정가를 뜻하지 않습니다.
- 프런트엔드 회귀 테스트: `node --test tests/test_dashboard_metrics.cjs` (공통 집계 단위 테스트와 저장된 날짜별 DOM 대역을 사용한 렌더링 검증). 실제 브라우저의 레이아웃 검증은 별도입니다.


### 주간·월간 인기 IP 기간 기준

- `7b15a4e`의 주간·월간 탭을 최신 main에 통합했습니다. 최근 7일·30일은 최신 수집일을 포함한 **달력 기간**이며, 실제 수집일 수를 별도로 표시합니다.
- 기간 탭은 최신 수집일 기준 보고서입니다. 상단 날짜 선택은 기존 일별 화면에 적용됩니다.
- 집계는 보존된 `docs/data_YYYYMMDD.json`에서 계산합니다. Actions의 새 환경에서도 CSV 마스터의 보존 여부에 영향을 받지 않습니다. 과거 CSV·JSON이나 IP 라벨은 재작성하지 않습니다.
- IP 비중의 분모는 선택 카테고리의 전체 랭킹 노출 건수입니다. 미분류·일반 상품을 IP 순위에서 제외하고, 복수 IP명은 각각 한 번씩 계산합니다. 매출·시장 점유율 지표가 아닙니다.
- 꾸준히 노출된 상품은 상품 ID별 고유 수집일 수로 집계합니다. 제목·가격 변경과 동일일 여러 카테고리 노출이 날짜 수를 늘리지 않습니다. 식별할 수 없는 상품은 제외합니다.
- 검증: `python -m unittest discover -s tests -p "test_*.py"`, `node --test tests/test_dashboard_metrics.cjs`.

### 직전 기간 대비 IP 모멘텀

- 자동 보고서 생성에서 `period_momentum.py`를 호출하여 주간·월간 각 카테고리의 `momentum`을 항상 저장합니다. 현재 기간 직전의 겹치지 않는 7일/30일과 비교합니다.
- 두 기간의 각 카테고리에 최소 절반(7일은 4일, 30일은 15일)의 관측일이 있어야 비교합니다. 부족하거나 순위가 누락·중복된 경우 비교 불가 사유를 표시합니다.
- 수집 범위가 Top 100에서 Top 50으로 바뀌어도 인위적인 하락이 생기지 않도록, 양쪽 기간의 카테고리별 공통 순위 범위 N만 사용합니다. 상품 노출 점수는 `N+1-순위`, IP 점수는 카테고리별 수집일당 평균 점수의 합입니다. 미수집일을 0점으로 처리하지 않습니다.
- 직전 대비 점수가 10% 이상 증가하면 상승, 10% 이상 감소하면 하락, 그 사이면 안정적 강세로 분류합니다. 직전 점수가 0이고 현재 관측되면 관측상 신규이며 출시 여부를 뜻하지 않습니다. 현재 사라진 IP도 -100% 하락에 포함합니다. 각 목록은 최대 10개입니다.
- 일반/비IP·미분류는 제외하고 복수 IP명은 각 IP에 한 번씩 반영합니다. 같은 날짜·카테고리·상품 ID의 중복은 제거하며, 동일 상품의 다른 카테고리 노출은 각각 반영합니다. 근거 상품은 ID별로 묶고, 현재 미관측 IP는 직전 기간 상품임을 명시합니다.
- 화면은 데이터 누락, 비교 자료 부족, 정상적인 결과 없음의 세 상태를 구분합니다. `verify_dashboard.py`가 모멘텀 필드 누락을 배포 전에 차단합니다. 매일 수집 전에 Python 회귀 테스트도 실행합니다.
- 점수와 변화율은 수집된 랭킹의 노출 지표이며 매출 성장률이 아닙니다.
