# IP 성장·하락 모멘텀 복구

## 원인

10월 27일 `208fba3`에는 화면과 모멘텀 JSON이 추가됐지만 자동 생성 함수에는 모멘텀 계산이 반영되지 않았다. 뒤이은 자동 수집 `c10b21f`와 `3b378c0`이 주간·월간 보고서를 재생성하면서 해당 필드를 지웠다. 화면은 필드 누락을 빈 목록으로 처리해 ‘해당 조건에 부합하는 IP가 없습니다’라고 표시했다.

## 수정

- `period_momentum.py`에 재현 가능한 계산을 구현하고 `generate_period_insights` 및 일일 자동 생성에 연결했다.
- 현재·직전 기간을 겹치지 않는 동일 길이의 달력 구간으로 분리한다. 각 카테고리의 최소 관측일 기준은 기간의 절반 이상이다.
- 카테고리별 공통 Top N 범위에서 `N+1-순위`를 합산하고 실제 수집일 수로 나눈다. 서로 다른 수집일 수와 Top 100/50 변경을 보정한다. 분류 기준은 ±10%이며 관측상 신규와 완전 미관측(-100%)을 구분한다.
- 현재·직전 점수, 차이, 관측일, Top 10 노출, 근거 상품을 저장한다. 일반/비IP 및 미분류는 제외한다. 근거 상품은 상품 ID별로 묶는다.
- 화면에서 데이터 누락, 관측 부족, 정상적인 결과 없음을 구분한다. 스크립트 버전을 변경해 브라우저가 수정 코드를 받도록 했다.
- 배포 검증은 주간·월간 보고서의 날짜·카테고리·모멘텀 구조를 검사한다. 일일 자동 작업에 Python 회귀 테스트를 추가했다.
- 앞서 PR #5에서 준비한 라이징 스타 중복 수정과 함께 배포한다. 수집 기록이나 날짜를 임의로 변경하지 않는다.
